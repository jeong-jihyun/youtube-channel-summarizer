# youtube-channel-summarizer

유튜브 채널의 영상 목록과 자막을 가져와 영상별로 요약하고, 채널 전체를 한눈에 보는 리포트로 정리하는 도구입니다.

## 하려는 일

1. 채널 주소(예: `https://www.youtube.com/@CONNECT-AI-LAB`)를 입력한다.
2. 영상 목록(제목, 길이, 조회수, 올린 날짜)을 가져온다.
3. 영상별 자막을 가져와 짧게 요약한다.
4. 채널 전체 요약 리포트(주제별 묶음, 최신 영상)를 만든다.

## 진행 상태

- [x] 저장소 생성
- [ ] 영상 목록 수집
- [ ] 자막 가져오기
- [ ] 영상별 요약
- [ ] 채널 리포트 출력

## 처리한 내용

- `summaries/<영상ID>.md` 영상별 요약, `projects/<분류>/<번호>-<이름>/` 모의 프로젝트. 관리표는 구글 시트에서 본다.
- 2026-11-12: 영상 5개 요약과 모의 프로젝트 0001~0005 추가.
