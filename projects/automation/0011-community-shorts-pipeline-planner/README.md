# 0011 커뮤니티 쇼츠 제작 설계기 (장면·음성 길이·제목·위험 점검·수익 시뮬)

## 어느 영상에서 왔나
- 제목: 퇴근 후 집에서 시작한 부업으로 월 5천 찍고 인생역전한 98년생 남자 (돈터치, 35분 28초)
- 주소: https://www.youtube.com/watch?v=zAA7lfTfq-I
- 요약: [summaries/zAA7lfTfq-I.md](../../../summaries/zAA7lfTfq-I.md) (자막 전체를 읽음)

## 영상이 알려 준 것(핵심)
- 커뮤니티·뉴스 사연을 각색한 '커뮤니티 쇼츠'를 하루 약 10편 올려 조회수·쇼핑·광고 수익을 낸다는 주장. 랭킹·연예인 쇼츠는 저작권 문제가 있고 사연형은 AI가 소재부터 대본까지 만든다고 한다.
- 제작 흐름: 사연 찾기 → 제목 10개·대본 → 장면 나누기(이미지 약 13개) → 음성(배속 1~2배, 쉼 줄이기 0.2초) → 편집(글꼴·효과) → 유튜브 오디오 보관함 음악 → 내보내기. 한 편 10~15분.
- 수치(화면 기준, 자막이 거칠다): 28일 약 2.1억 조회에 예상 수익 3,400만원, 하루 조회수 수익 최고 약 220만원. 16개 공식·프로그램은 공개되지 않았다.

## 무엇을 만들었나
`shorts.py` 의 `api()` 한 번으로 아래를 낸다(영상 속 프로그램을 복제한 것이 아니라 그 흐름의 계산·점검 부분을 도구화).
1. 음성 길이 추정: 글자 수 ÷ (1배속 글자/초 x 배속) + 문장 수 x 쉼. 쇼츠 최대 길이를 넘으면 필요한 배속 또는 줄일 글자 수를 알려 준다.
2. 장면 나누기와 장면별 길이·이미지 프롬프트(목표 장면 수 지정).
3. 제목 후보 10개(핵심어를 뽑아 끼우는 경험칙 틀. 영상의 16개 공식은 공개되지 않았다).
4. 개인정보·위험 점검(전화번호·이메일·주민번호 형태·주소 형태·링크·민감 표현).
5. 원문과 각색 대본 비교: 80% 이상 같은 문장 비율과 5글자 연속 겹침 비율로 그대로 베낀 정도를 경고(저작권 판단은 아님).
6. 수익 시뮬레이션: 하루 편수 x 30일 x 편당 조회수 x RPM, RPM 절반 시나리오, 영상 화면 숫자 환산 RPM(약 162원), '하루 천만 조회 x 월 5천만원' 주장이 요구하는 RPM(약 167원)과 비교.

## 실제 실행 결과(실제 실행)
- 내가 직접 지어낸 예시 사연(212자, 10문장), 배속 1.2배, 쉼 0.2초: 추정 약 31초로 60초 이내, 10장면, 제목 핵심어 '업체'.
- 예시를 편수 10 x 30일 x 조회 2만 x RPM 160원으로 계산하면 월 조회수 수익 약 96만원, 영상의 월 4천만원에 도달하려면 같은 가정에서 하루 약 417편이 필요하다. 영상 화면 환산 RPM 약 162원은 입력 기본값(160원)과 거의 같다.
- 원문을 그대로 복사해 각색본으로 넣으면 같은 문장 비율 100%로 '더 바꿀 것' 경고, 다르게 쓴 대본은 통과. 전화번호·이메일·주소 형태 발견 시험 통과.
- 자동 시험 17개 통과(배속·쉼 영향, 길이 초과 안내, 장면 수, 개인정보, 유사도, 수익 계산).

## 한계(미확인)
- 영상 속 프로그램(사연 자동 수집, 이미지·음성·영상 생성)은 만들지 않았고 외부 서비스도 호출하지 않는다. 글자/초(6자), RPM(160원)은 가정이며 실제 TTS와 채널에 따라 크게 다르다. RPM 환산은 자막의 거친 숫자(2.1억, 3,400만원)에 의존한다.
- 유사도 점검은 문장 표면 비교라서 의미를 바꾼 베끼기·저작권·초상권·명예훼손을 판단하지 못한다. 쇼츠 수익화 기준(영상 발언: 2026년 2월 변경)과 쇼츠 최대 길이는 유튜브 정책을 직접 확인해야 한다.
- 투자·사업 권유가 아니며 수익을 보장하지 않는다.

## 이렇게 활용할 수 있어요
- 사연 글을 넣으면 문장 단위로 장면을 나눠 장면별 이미지 프롬프트와 길이를 받아 이미지 약 13장 흐름을 바로 짠다.
- 배속·문장 사이 쉼을 바꿔 가며 쇼츠 60초 안에 들어오는지 보고, 넘으면 얼마나 줄이거나 배속을 올려야 하는지 확인한다.
- 원문과 내가 고친 대본을 같이 넣어 그대로 옮긴 문장 비율을 보고, 전화번호·이메일·주소 형태·민감 표현을 올리기 전에 걸러 낸다.
- 하루 편수·편당 조회수·RPM을 넣어 월 수익을 가정으로 계산하고, 영상의 '하루 천만 조회·월 5천' 주장이 요구하는 RPM과 비교한다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from shorts import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포

```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
