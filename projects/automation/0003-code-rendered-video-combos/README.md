- 주소: https://www.youtube.com/watch?v=Yz3124ulHKE
- 요약: [summaries/Yz3124ulHKE.md](../../../summaries/Yz3124ulHKE.md)

## 무엇을 하나
블렌더 대신 numpy+Pillow로 점 모델 장면(바닥 격자와 공)을 한 번 만들고, 카메라만 돌려 24프레임을 렌더해 orbit.gif로 저장한다. 날짜로 모자×캐릭터×신발 18가지 조합 중 하나를 고르는 부분도 있다. 블렌더·MCP·유료 API는 쓰지 않았다(모의).

## 실행 방법
```
pip install numpy pillow   # 이미 있으면 생략
python3 render.py
```

## 직접 실행한 결과 (2026-11-12)
```
오늘의 조합: 파랑 모자 / 토끼 / 운동화
프레임 수: 24 / 0번과 6번 프레임 차이: 192606
18일 동안 서로 다른 조합 수: 18
성공
```

상태: **동작 확인** — 프레임이 실제로 달라지는지 숫자로 검사했다. GIF 모양을 눈으로 직접 보지는 않았다. 조합(모자 등)은 이름만 고르고 화면에는 공 색으로만 반영된다.

## 이렇게 활용할 수 있어요
- 영상 자동화의 뼈대(장면 1번 만들기 → 카메라 경로로 렌더 → 날짜별 조합)를 블렌더 없이 먼저 시험한다.
- 모자×캐릭터×신발 같은 조합표로 매일 다른 콘텐츠 기획안을 뽑는 도구로 쓴다(18가지, 날짜로 고정 선택).
- 나중에 실제 블렌더 파이썬 스크립트로 옮길 때 조합 고르기와 프레임 생성 로직을 그대로 가져간다.
- 영상 생성 API 없이 코드 렌더로 비용을 아끼는 방식이 내 채널에 맞는지 작게 체험한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '코드로 렌더하는 영상과 매일 조합' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from render import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
