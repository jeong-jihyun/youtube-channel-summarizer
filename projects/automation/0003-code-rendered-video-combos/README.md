## 무엇을 하나
블렌더 대신 numpy+Pillow로 점 모델 장면(바닥 격자와 공)을 한 번 만들고, 카메라만 돌려 24프레임을 렌더해 orbit.gif로 저장한다. 날짜로 모자×캐릭터×신발 18가지 조합 중 하나를 고르는 부분도 있다. 블렌더·MCP·유료 API는 쓰지 않았다(모의).

## 실행 방법
```
pip install numpy pillow   # 이미 있으면 생략
python3 render.py
```
