# 0003 블렌더 영상 오토파일럿 키트

- 제목: AI 직원들이 밤새 영상 만드는 1인 기업 | 영상 바이브코딩으로 AI 자율 회사 만들기 (35분)
- 주소: https://www.youtube.com/watch?v=Yz3124ulHKE
- 요약: [summaries/Yz3124ulHKE.md](../../../summaries/Yz3124ulHKE.md)

## 영상이 알려 준 것(핵심)
- 영상을 '생성'하면 매번 비용이 들고 일부만 고치기 어렵다. 대신 3D 장면을 한 번 만들어 두고 카메라를 돌려 렌더하면(바이브 코딩) 비용이 거의 없고, 캐릭터 얼굴이 안 바뀌고, 코드라 자동화가 쉽다.
- 3단계: 모델링(세트장) -> 애니메이션(카메라·캐릭터 키프레임) -> 렌더링(프레임을 이미지로 뽑아 영상). 영상은 프레임이 이어진 것(1~60프레임이 모이면 영상).
- 블렌더는 무료·오픈소스. Blender MCP로 Claude·Codex·Antigravity를 연결하면 말로 시킨 것을 파이썬 코드로 실행하고, 결과를 보고 고치기를 반복한다. 블렌더와 AI 도구가 모두 켜져 있어야 하며 연결 포트는 9876(영상 언급).
- 재질에 따라 물리가 다르다(천은 감기고 쇠는 툭 얹힌다). 파일(.blend)이 곧 자산이라 저장해 두면 다시 쓴다. 여러 AI가 한 장면을 나눠 만드는 것을 Distributed AI라고 부른다.
- 오토파일럿: 장면 파일, 시각(예: 아침 8시), 길이, 화면 크기(세로 1080x1920/가로), 매일 바꿀 것, 절대 바꾸지 말 것(로고·워터마크)을 적은 프롬프트를 AI에 주면 밤새 렌더해 아침에 올린다. 모자·캐릭터·장갑·신발 각 10가지면 조합으로 매일 다른 영상이 나온다.
- 자동화(내가 정한 규칙대로)와 자율화(목표를 주면 AI가 판단)는 다르다.

## 무엇을 만들었나
- `blender_scene.py`: 영상의 장면을 코드로 옮긴 블렌더(bpy) 스크립트. 반짝이는 빨간 공, 무지개, 공 위로 떨어져 감기는 천(물리), 하늘, 공 둘레 360도 카메라 키프레임, 세로/가로 해상도, PNG 프레임 렌더, 장면 .blend 저장, ffmpeg로 mp4 묶기.
- `autopilot.py`: 영상 속 프롬프트 구조 그대로 '오토파일럿 프롬프트' 생성, 조합표에서 날짜별 조합 선택(겹침 없음), 프레임 수·해상도 계산, 렌더 명령 생성.

## 실행 결과(실제 실행)
- 실제 블렌더(bpy 5.3) 렌더: 1080x1920 설정으로 24프레임 렌더 성공(시험은 5% 크기), 프레임마다 카메라 위치가 달라짐을 이미지로 확인, 천이 공 위로 떨어져 덮는 것 확인(떨어짐 -1.0 이상을 자동 시험), PNG -> mp4 변환(ffmpeg) 성공.
- 조합표 4칸x10가지 = 10,000가지, 1,000일 동안 겹치지 않음 시험 통과. 10초 24fps = 240프레임.

## 한계(미확인)
- 전체 해상도(1080x1920)·긴 길이 렌더 시간은 재 보지 않았다(시험은 작은 크기). 고품질 장면(영상의 Sunset Villa 등)은 영상 제작자의 파일이라 포함하지 않았다.
- Blender MCP로 Claude·Codex·Antigravity를 실제로 연결해 본 것은 아니다. 프롬프트 생성까지 하고 연결은 영상·교재 안내를 따라야 한다.
- 유튜브·인스타 자동 업로드는 만들지 않았다(계정 연결이 필요).

## 이렇게 활용할 수 있어요
- 아침마다 AI 코딩 도구(Claude Code·Codex·Antigravity)에 그대로 붙여 넣을 '영상 오토파일럿 프롬프트'를 만든다(장면 파일·시각·길이·화면 크기·바꿀 것·바꾸지 말 것·오늘의 조합).
- 모자·캐릭터·장갑·신발 각 10가지면 1만 가지 조합이 나온다. 날짜별로 같은 조합이 겹치지 않게 골라 매일 다른 캐릭터 콘텐츠를 만든다.
- blender_scene.py 를 블렌더에서 실행하면 빨간 공·무지개·천(물리)·하늘 장면을 만들고 카메라가 360도 도는 영상 프레임을 렌더한다. 장면을 .blend 로 저장해 두면 영상 생성 API 비용 없이 재사용한다.
- 영상 길이(초)×fps 로 프레임 수를, 세로 1080x1920/가로 1920x1080 해상도를 바로 계산해 렌더 시간을 가늠한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '블렌더 영상 오토파일럿 키트' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from autopilot import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
