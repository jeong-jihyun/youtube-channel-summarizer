# AI 1인 사업 사이트 출시 키트

## 어느 영상에서 왔나
CONNECT AI LAB 'Start an AI Solo Business for 0 Won | EP.1' (https://www.youtube.com/watch?v=l_BNmIsuNVU, 26:47, 2026-05-30). 영어 제공 자막 전체(약 2만 3천 자)를 끝까지 읽었다.

## 영상이 알려 준 것(핵심)
- 구글 Stitch 2.0에 Design.md(색·글꼴·버튼 모서리 규칙)를 먼저 올려 사이트를 디자인한다. 바꿀 때는 Gemini에게 Design.md를 고치게 한다.
- 메인 → 상세 → 라이브러리 → 구매 완료·다운로드 순으로 여러 페이지를 만들고, 결제는 카드+PayPal만 남긴다.
- Stripe는 한국에서 공식 사용이 안 되고 미국 법인(Stripe Atlas)이 필요해 초기 비용이 있으므로 PayPal로 시작. 한국 결제는 토스페이먼츠.
- Stitch → Export → MCP → API 키 → Antigravity IDE에 Stitch MCP 설치 → 프롬프트 붙여 넣기 → 화면·코드 가져오기 → React로 localhost 개발.
- 고객 시점으로 시뮬레이션하고, 오류는 통째로 복사해 붙여 넣어 자동 수정. 다음 편은 데이터베이스와 PayPal 결제 연결.

## 무엇을 만들었나
`site_kit.py` 의 `api()` 가 한 번에 낸다: ① Design.md 본문과 색 대비비(WCAG 계산, 4.5:1 미만 경고) ② 페이지별 프롬프트 ③ 결제 수단 비교(영상 조건 반영: 해외 고객이면 토스 제외, Stripe는 초기 비용을 12개월로 나눠 반영) + Design.md 수정 요청문 + Antigravity 지시문 5개 ④ 영상 순서 체크리스트 ⑤ 고객 시점 점검표.

## 실제 실행 결과(기본 입력: 전자책 19,900원, 월 30건, 해외 고객 있음)
  1위 PayPal: 건당 수수료 1,296원, 건당 실수령 18,604원, 월 실수령 558,120원 [바로 사용]
  2위 Stripe: 건당 수수료 996원, 건당 실수령 18,904원, 월 실수령 508,772원 [조건부(미국 법인 등 준비 필요, 초기비용 700,000원을 12개월로 나눠 반영)]
  제외 토스페이먼츠: 불가(해외 고객 결제 안 됨)

- 대비비 계산은 검은색/흰색 21.0:1 같은 기준값으로 확인했고, 노란색 주색+회색 글자는 두 항목 모두 경고된다. 시험 13개(표준 3종 + 추가 10개) 통과. 월 3,000건이면 순위가 Stripe로 뒤집히는 것도 시험으로 확인.
- 시험 중 발견·수정한 오류: '구매 완료·다운로드' 페이지가 결제 안내가 아닌 다운로드 안내로 잘못 분류되던 것을 고쳤다.

## 한계(미확인)
- Stitch·Antigravity·MCP 연결은 직접 실행하지 않았다(체크리스트와 지시문만 제공). 화면·요금은 영상 시점(2026-05)이다.
- 결제 수수료(PayPal 4%+500원, Stripe 3.5%+300원, 토스 3%)와 미국 법인 초기 비용 70만 원은 영상에 없는 가정값이다. 공식 요금표로 바꿔야 한다.
- 자막은 영어 제공 자막이라 번역 오류 가능성이 있다. 결제·세금·법인 문제는 전문가 확인이 필요하다.

## 이렇게 활용할 수 있어요
- 브랜드·색·글꼴·버튼 모양을 넣으면 Stitch에 올릴 Design.md를 만들고, 글자/배경·버튼 글자/주색의 대비비(WCAG 4.5:1)를 계산해 읽기 어려운 색을 미리 잡는다.
- 메인·상세·라이브러리·구매 완료 페이지별 프롬프트를 같은 디자인 규칙으로 만들어, 페이지마다 모양이 달라지는 것을 막는다.
- 해외 고객 여부와 수수료·미국 법인 초기비용을 넣으면 PayPal·Stripe·토스를 영상의 조건(Stripe는 한국 공식 불가, 토스는 한국 결제)으로 걸러 월 실수령으로 비교한다.
- Stitch→MCP→Antigravity 연결 순서와 React 개발·고객 시점 시뮬레이션·오류 붙여 넣기 지시문을 체크리스트로 따라 하며 막힌 곳을 확인한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 'AI 1인 사업 사이트 출시 키트(Design.md·페이지 지시문·결제 조건 비교·Antigravity 지시문)' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from site_kit import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
