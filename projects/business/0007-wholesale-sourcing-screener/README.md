# 0007 도매 소싱 후보 점검기 (순마진·유통기한·묶음·재고자금)

## 어느 영상에서 왔나
- 제목: "75세도 100원에 사서 15,000원에 팔아요" 100분의 1 가격 아지트에서 월 2000 버는 58세 주부 부업 (돈터치, 30분)
- 주소: https://www.youtube.com/watch?v=JYmuv39Ka64
- 요약: [summaries/JYmuv39Ka64.md](../../../summaries/JYmuv39Ka64.md) (자막 전체를 읽음)

## 영상이 알려 준 것(핵심)
- 도매 창고에서 쿠팡 판매가의 수분의 1 가격에 사서 되파는 소싱. 정보(어디서 싸게 사는지)가 돈이라는 주장.
- 품목 선택 기준: 객단가가 높고 재구매가 일어나는 건강식품·화장품, 500~1,000원 소품은 묶음 판매, 유통기한이 한참 남은 물건.
- 운영: 상품 10개 안쪽, 주력 서너 개, 광고 없이, 상세페이지에 공들이지 않음. 마진은 보통 20% 이상, 묶음은 30~50%. 월 매출 2,000만원에 순수익 약 400만원.
- 영상은 소싱처(창고·프로그램)를 공개하지 않고 무료 강의·전자책 유도로 끝나는 광고 성격이다.

## 무엇을 만들었나
`screener.py` 의 `api()` 가 품목 줄(`이름,개당 매입가,묶음 개수,묶음 판매가,유통기한,재구매`)을 읽어 다음을 계산한다.
1. 품목별 '영상식 총마진'과, 판매 수수료·배송비·포장비·반품 손실을 뺀 '순마진'을 나란히 보여 주고 후보/보류/제외로 가른다(목표 순마진, 유통기한 최소 개월, 최소 객단가 기준).
2. 같은 상품을 개당 1개씩 팔 때와 묶음으로 팔 때의 건당 순이익 비교(배송비가 고정이라 묶음이 유리한지).
3. 월 매출 시나리오: 후보 평균 순마진, 하루 필요한 주문 수, 먼저 사 둘 재고 자금, 영상의 '2,000만원 x 20% = 400만원' 점검, 영상 속 가격 격차와 실제 마진 주장 사이의 불일치 경고.

## 실제 실행 결과(실제 실행)
- 영상 속 가격 쌍으로 만든 예시 8개(수수료 10%, 배송 3,000원, 포장 500원, 반품 3% 가정): 후보 5개, 보류 3개(유통기한 5.6·4.6·1.3개월). 수세미 세트처럼 1만원짜리는 순마진 23%로 비용 반영 후 가장 얇다.
- 묶음 효과: 수세미 3개 묶음 순이익 2,293원, 같은 상품을 1개씩 팔면 -1,689원(배송비 때문).
- 월 2,000만원 시나리오: 영상식 총마진으로는 월 약 1,607만원이지만 비용 반영 순마진 52%로는 약 1,036만원, 재고 자금 약 394만원, 하루 약 23건 주문. 영상 속 가격 격차(총마진 약 80%)와 영상이 말한 실제 마진(20%)이 크게 달라 입력값 점검이 필요하다는 경고가 나온다.
- 자동 시험 13개 통과(순마진 계산식, 유통기한 지남·임박, 손실 제외, 낮은 마진 보류, 묶음 효과, 반품 영향, 재고 자금, 입력 오류).

## 한계(미확인)
- 수수료율·배송비·포장비·반품률은 가정값이다. 쿠팡 실제 수수료는 카테고리마다 다르고 이 도구에 넣지 않았다. 판매가는 영상 속 쿠팡 화면 가격을 예시로 넣은 것이며 실제로 그 가격에 팔린다는 보장이 없다.
- 유통기한 6개월, 객단가 1만원은 영상에서 수치로 말한 기준이 아니라 내가 정한 경험칙이다.
- 소싱처·프로그램은 영상에서 공개되지 않아 확인하지 못했다. 정품 여부, 유통기한 표시, 건강기능식품 판매 신고 등 법적 요건은 계산하지 않는다. 투자·사업 권유가 아니며 수익을 보장하지 않는다.

## 이렇게 활용할 수 있어요
- 창고·도매 현장에서 본 품목의 매입가와 내가 팔 가격을 한 줄씩 넣어 수수료·배송·반품까지 반영한 순마진으로 사 올 만한지(후보/보류/제외) 바로 가른다.
- 단품과 묶음의 건당 순이익 차이를 보고 몇 개 묶어 팔아야 배송비를 감당하는지 정한다(영상: 500~1,000원 소품은 묶어서 판다).
- 유통기한 날짜를 넣어 6개월 미만 품목을 걸러 내고, 재구매가 일어나는 품목(건강식품 등)을 우선 고른다.
- 목표 월 매출을 넣어 하루 필요한 주문 수와 미리 사 둘 재고 자금을 계산해 선매입 위험(안 팔리면 재고 손실)을 먼저 본다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '도매 소싱 후보 점검기(순마진·유통기한·묶음·재고자금)' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from screener import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
