# 0010 숏폼 대행 견적·순수익 점검 + 고객용 기획서 뼈대

## 어느 영상에서 왔나
- 제목: "72세도 돈 벌고 일본 여행 가셨어요" 영상 전달만 하며 월 4천 버는 역대급 자택 부업 (돈터치, 29분 52초)
- 주소: https://www.youtube.com/watch?v=t3-xEAagHDs
- 요약: [summaries/t3-xEAagHDs.md](../../../summaries/t3-xEAagHDs.md) (자막 전체를 읽음)

## 영상이 알려 준 것(핵심)
- 인스타 릴스 제작을 고객 대신 해 주는 '숏폼 대행'. 선입금 패키지(월 8건 x 3개월)를 받고 편집은 외주로 돌려 순수익 60~70%, 고객 13곳, 하루 약 1시간이라고 말한다.
- 기획서(제목·스토리보드·촬영 가이드·대본·캡션)를 AI로 만들어 PDF로 고객 확인 → 편집자 전달. ChatGPT에는 '이런 제목을 짓고 싶은데 뭐라고 물어보면 돼?'로 요청 공식을 먼저 받는다.
- AI 영상: 전/후 이미지 2장 → 시작·끝 프레임 지정 → 편집 앱에서 컷·속도·음악, 약 30분.
- 프로그램·알고리즘 자료는 공개되지 않았고 무료특강·단톡방 유도로 끝나는 광고 성격이다.

## 무엇을 만들었나
`agency.py` 의 `api()` 한 번으로 두 가지를 낸다.
1. 견적·순수익: 패키지(월 건수·개월·총액)와 외주비·내 시간·고객 수를 넣으면 건당 단가, 순수익률, 고객 1곳 시간당 수입, 고객 전체 월 순이익과 하루 작업 시간을 계산하고, 영상의 숫자를 점검한다(660만원 계산, 월 4천에 필요한 고객 수, 하루 1시간).
2. 기획서: 업종·주제·길이를 넣으면 제목 후보 5개, 시간대별 스토리보드, 촬영 가이드, 캡션, 금지 표현 점검, ChatGPT 요청 문구, AI 시작/끝 이미지 프롬프트, 편집자 체크, 주 N회 업로드 일정을 만든다. 기획서 문장은 규칙 기반 뼈대이며 사람이 업종 사실로 채운다.

## 실제 실행 결과(실제 실행)
- 기본값(월 8건 x 3개월 660만원, 외주 건당 3만원, 건당 20분, 13곳): 영상 24건, 건당 275,000원, 순수익률 약 89%, 고객 13곳 월 순이익 약 2,538만원, 하루 작업 1.2시간.
- 영상 주장 점검 결과: '200만원씩 3개월 = 660만원'은 600만원이라 불일치, 월 순수익 4천만원(순수익률 65%)은 이 단가로 고객 약 28곳이 필요해 13곳으로는 설명되지 않는다고 경고한다.
- 외주비를 건당 4.5만원으로 올리면 순수익률이 약 89%에서 약 83%로 낮아진다. 영상의 60~70%를 맞추려면 건당 단가 27.5만원 중 외주비가 약 8~11만원이어야 하므로, 영상 속 순수익률은 외주비를 더 많이 쓴다는 뜻이거나 단가가 다르다는 뜻이다.
- 자동 시험 통과(계산식, 외주비 영향, 경고 문구, 금지어, 의료 업종 문구, 일정 개수, 잘못된 입력).

## 한계(미확인)
- 외주비·내 시간·툴 비용은 가정값이다. 영상 속 프로그램(기획서 생성기)과 알고리즘 자료는 보지 못해 같은 품질을 보장하지 않는다. 제목 틀 5종은 내가 정한 경험칙이다.
- 세금·부가세·고객 이탈·수정 요청·광고 심의는 계산하지 않는다. 의료 고객은 의료광고 규정을 직접 확인해야 한다.
- 투자·사업 권유가 아니며 수익을 보장하지 않는다.

## 이렇게 활용할 수 있어요
- 고객에게 제안할 패키지(월 건수·개월·총액)를 넣어 건당 단가·외주비 뺀 순수익률·고객 1곳당 시간당 수입을 계약 전에 계산한다.
- 영상의 '월 4천·순수익 60~70%·13업체·하루 1시간' 주장을 내 숫자로 바꿔 넣어 필요한 고객 수와 하루 작업 시간을 역산한다.
- 업종·주제만 넣으면 고객에게 보낼 기획서 뼈대(제목 후보, 시간대별 스토리보드, 촬영 가이드, 캡션)와 금지 표현 점검을 얻는다.
- ChatGPT 요청 문구, AI 시작/끝 이미지 프롬프트, 편집자 전달 체크리스트, 주 N회 업로드 일정을 복사해 바로 쓴다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '숏폼 대행 견적·순수익 점검 + 고객용 기획서 뼈대' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from agency import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
