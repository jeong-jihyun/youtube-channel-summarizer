# 0004 AI 1인 기업 운영 키트

## 어느 영상에서 왔나
- 제목: 2023년부터 직접 다 해본 AI 1인 기업 자동화 (THE FOUNDER EP.1, 23분)
- 주소: https://www.youtube.com/watch?v=VD9OCNkJ8Dw
- 요약: [summaries/VD9OCNkJ8Dw.md](../../../summaries/VD9OCNkJ8Dw.md)

## 영상이 알려 준 것(핵심)
- 한 번의 프롬프트로 월 1억을 버는 AI는 아직 없다. 단순 바이브 코딩이나 콘텐츠 업로드만으로는 AI 1인 기업이 아니다.
- 경영 방식이 바뀐다: 매일 아침 8시 AI가 인스타·X·유튜브·블로그를 보고 아이디어를 가져오고, 사람은 고르고 지시한다. 만들고, 안 되면 버리고, 다시 만든다.
- 하루 4사이클: 기획 -> 개발(MVP에는 최고 모델 불필요) -> 마케팅 -> 운영. 투자·런웨이로 생각한다(예산이 1억이면 수익 없이 며칠 버티는지 계산하고, 마감일까지 안 되면 중단).
- 비용: 토큰·전기·월세를 계산하고, 품질이 덜 필요한 일은 작은 모델이나 로컬 AI(무료)로 보낸다. 컴퓨터끼리 일을 나눈다(울트라는 블렌더, 맥북은 바이브 코딩, 가벼운 모델은 분석).
- CEO가 아니라 투자자처럼: 100개를 만들어 몇 개만 성공하면 된다. 속도가 전부이고 리버스 엔지니어링이 흔해서 비용 최적화가 더 중요하다. 시작은 AI 모델 하나, 로컬 AI 하나, 컴퓨터 한 대면 충분하다.
- 가장 중요한 건 나의 중심(건강·삶·가치).

## 무엇을 만들었나
`founder.py`: 런웨이와 중단 마감일, 작업별 모델 라우팅과 절감률, 내 컴퓨터 램 표로 작업 배정, 투자자 포트폴리오(성공 확률 1·3·5%), 하루 루틴표를 한 번에 계산한다. 모델·작업·컴퓨터 표는 입력으로 받아 내 값으로 바꿀 수 있다.

## 실행 결과(실제 실행)
- 기본값(예산 100만원, 작업당 5만 토큰): 하루 소모 3,400원 -> 294일, 중단일 2027-09-02. 전부 최고 모델 7,500원/일 -> 분배 1,900원/일(절감 75%).
- 컴퓨터 배정: 블렌더 렌더 -> 울트라, 영상 로컬 생성 -> 프로, 바이브 코딩 -> 맥북 프로, 분석 -> 작은 서버.
- 아이디어 100개: 성공 확률 1% -> 한 개 이상 성공 63.4%, 3% -> 95.2%, 5% -> 99.4%. 자동 시험 통과.

## 한계(미확인)
- 모델 가격·성공 확률·램·성공당 수익은 모두 가정값이다. 영상이 말한 숫자는 '100개 중 몇 개', '1%->3%->5% 예시' 정도다.
- 실제 모델 가격표나 내 컴퓨터를 읽어 오지 않는다(표를 직접 입력).

## 이렇게 활용할 수 있어요
- 예산과 하루 운영비(토큰+전기+월세)를 넣어 며칠 버티는지와 '이 날까지 성과 없으면 중단' 마감일을 바로 정한다. 프로젝트마다 중단 기준일을 먼저 정하는 용도다.
- 작업별로 큰 모델·작은 모델·로컬 AI 중 어디로 보낼지 정하고 전부 큰 모델 대비 절감률을 본다. 모델 표와 작업 표를 내 실제 가격으로 바꿔 비용 시뮬레이터로 쓴다.
- 내 컴퓨터 램 표를 넣으면 3D 렌더·로컬 생성·바이브 코딩·분석 작업을 어느 컴퓨터에 맡길지 배정한다(영상: 울트라는 블렌더, 맥북은 바이브 코딩, 가벼운 모델은 분석).
- '100개 만들어 2~3개만 성공해도 된다'는 투자자 관점을 숫자로 본다: 성공 확률 1·3·5%일 때 한 개 이상 성공할 확률과 본전이 되는 성공당 수익.
- 아침 8시 회의부터 기획·개발·마케팅·운영 하루 루틴표를 그대로 가져가 내 일정으로 고쳐 쓴다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 'AI 1인 기업 운영 키트(런웨이·모델·컴퓨터·포트폴리오)' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from founder import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
