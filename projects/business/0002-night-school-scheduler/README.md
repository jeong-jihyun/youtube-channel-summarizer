# 0002 AI 야학당 수강 플래너

## 어느 영상에서 왔나
- 제목: 지금은 AI 문맹에서 벗어나야 합니다 (AI 야학당, 매일 저녁 8시, 3분 48초)
- 주소: https://www.youtube.com/watch?v=0Hif6Y40uC8
- 요약: [summaries/0Hif6Y40uC8.md](../../../summaries/0Hif6Y40uC8.md)

## 영상이 알려 준 것(핵심)
- 11월 11일(수) 시작, 11~12월 두 달. 월~금 저녁 8시 무료 공개 라이브(입문자), 토~일은 멤버십 전용 심화(주 2회, 함께 프로젝트·피드백).
- 주제는 '인공지능 자율화 회사 만들기'. 이론·실습·개발·자동화·자율화·에이전트와 AI 1인 기업 분석, 키워드는 생존·수익화·기회.
- 외부 일정으로 시간이 바뀔 수 있고 변경은 채널 게시글로 알린다(알림 설정 필요). 낮에는 일하고 저녁 8시에 공부하는 사람이 대상.
- 이 영상은 3분짜리 안내 영상이라 기술 노하우보다 '일정과 취지'가 전부다. 그래서 일정·출석 관리 도구로 만들었다.

## 무엇을 만들었나
`schedule.py`: (1) 알림이 들어간 달력 파일(.ics, 멤버십이 아니면 주말 제외, 고정 UID라 다시 가져오면 갱신), (2) 출석한 날짜를 넣으면 출석률·연속 출석·이번 주 남은 회차, (3) 회차별 학습 기록 양식.

## 실행 결과(실제 실행)
- 기본(11/11~12/31, 비회원): 37회(전부 공개). 멤버십 포함이면 51회(주말 14일 추가).
- 기준일 11/20, 출석 5일 입력 -> 8회 중 5회(62%).
- 만들어진 .ics를 표준 달력 파서(icalendar)로 읽어 51개 일정, 한국 시간 20:00, 30분 전 알림까지 확인. 자동 시험 통과.

## 한계(미확인)
- 실제 구글·삼성 달력 앱에 가져와 본 것은 아니다(표준 파서 검증까지).
- 일정은 방송 사정으로 바뀔 수 있어 게시글 공지를 따로 봐야 한다.

## 이렇게 활용할 수 있어요
- 야학당 일정을 알림(미리 N분)이 들어간 .ics 파일로 받아 휴대폰 달력에 한 번에 넣는다. 멤버십이 아니면 주말 일정은 자동으로 빼고, 일정이 바뀌면 같은 파일을 다시 가져와 갱신한다.
- 출석한 날짜를 넣으면 출석률·연속 출석·이번 주 남은 회차를 계산해, 낮에는 일하고 저녁 8시에 공부하는 루틴이 이어지는지 확인한다.
- 회차마다 배운 것 한 줄, 써먹을 것 한 가지, 해 본 실습을 남기는 학습 기록 양식을 받아 노션·메모에 붙여 쓴다(이론·실습·개발·자동화·자율화·에이전트·1인 기업 분석 분야 체크 포함).
- 날짜 범위와 요일 규칙을 바꿔 다른 스터디·정기 라이브 일정표로 재사용한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 'AI 야학당 수강 플래너' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from schedule import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
