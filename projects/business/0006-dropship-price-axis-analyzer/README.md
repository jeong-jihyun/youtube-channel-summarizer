# 0006 무재고 유통 키트 (판매가·등록시간·팔린 이유 4축)

## 어느 영상에서 왔나
- 제목: "아무리 알려줘도 안 해요" 200억 매출 찍고 인생 역전하게 된 40대 전 공무원 (돈터치, 24분)
- 주소: https://www.youtube.com/watch?v=7xFQfU_fZUI
- 요약: [summaries/7xFQfU_fZUI.md](../../../summaries/7xFQfU_fZUI.md) (자막 전체를 읽음)

## 영상이 알려 준 것(핵심)
- 무재고 유통: 남의 상품 정보를 내 마켓에 올리고, 주문이 오면 그때 사서 보낸다. 팔린 뒤 원가를 내므로 재고 위험이 없다고 한다.
- 가격: 원가(100유로 x 환율 1,500)에 마켓 수수료 약 7%와 마진 15~20%를 넣어 '1.4배'로 판매가를 정한다(21만원).
- 속도: 수동 등록은 1개 20~30분, 프로그램은 약 10초. 많이 올려 팔리는 곳('어장')을 찾아 더 넣는다.
- 분석: 팔린 이유는 브랜드·카테고리·키워드·시즌 중 하나다. 판매 이력을 이 4축으로 나눠 본다.
- 광고 없이 신규 셀러·신규 상품 노출 슬롯을 노린다. 영상은 프로그램·전자책 판매 광고를 겸한다.

## 무엇을 만들었나
`dropship.py` 의 `api()` 하나가 세 가지를 계산한다.
1. 판매가: 영상식 '곱하기' 방식과, 수수료·목표 마진·건당 비용을 넣어 거꾸로 구하는 방식을 나란히 보여 주고 곱하기 배수가 목표 마진을 맞추는지 점검한다.
2. 등록 시간: 상품 수 x (수동 분/개, 프로그램 초/개)로 총 시간과 일 수를 계산한다.
3. 4축 분석: `상품명,브랜드,카테고리,키워드1/키워드2,시즌,판매수` 줄을 붙여 넣으면 축별 '판매 점유 / 등록 점유'(lift)와, 각 축이 판매 차이를 설명하는 정도(설명력)를 구해 어느 축에 더 등록할지 알려 준다.

## 실제 실행 결과(실제 실행)
- 100유로 x 1,500원 x 1.4 = 210,000원(영상의 21만원과 일치). 수수료 7%를 내면 45,300원 남아 순마진율 21.6%. 마진 20% 목표로 역산하면 205,500원이고, 곱하기 1.4는 충분하다고 판정.
- 영상은 '10분 x 1만 개 = 11년'이라고 했으나 계산하면 100,000분, 쉬지 않고 약 69일이다. 수동 25분이면 4,167시간(하루 8시간 일해 521일), 프로그램 10초면 27.8시간.
- 내가 만든 예시 판매 이력 12개(스피도 물안경 사례): 브랜드 82%, 키워드 40%, 카테고리 33%, 시즌 29% 순으로 브랜드가 가장 설명력이 크다. 스피도 lift 2.43.
- 자동 시험 13개 통과(영상 숫자, 역산 마진 충족, 불가능한 마진, 비용 영향, 축 분석 정답 시나리오, 입력 오류 등).

## 한계(미확인)
- 수수료율·마진·환율·판매 이력은 모두 가정값이다. 판매 이력 예시는 영상 속 '스피도 물안경' 설명에 맞춰 내가 만든 가짜 데이터다.
- 실제 마켓 수수료, 반품·교환·배송 지연, 상표권·이미지 저작권 문제는 계산하지 않는다. 영상의 'AI로 바꾸면 지재권을 피한다'는 주장은 법적으로 확인되지 않았다.
- 영상 속 매출 수치와 프로그램 성능은 검증하지 못했다. 투자·사업 권유가 아니며 수익을 보장하지 않는다.

## 이렇게 활용할 수 있어요
- 해외·국내 상품 원가와 환율을 넣어 영상식 '곱하기 1.4'가 내 수수료·목표 마진을 정말 맞추는지 확인하고, 안 맞으면 역산한 판매가로 바꾼다.
- 올리려는 상품 수와 내 등록 속도(분/개)를 넣어 수동으로 며칠이 걸리고 프로그램을 쓰면 몇 시간인지 보고 도구 구입 여부를 판단한다.
- 내 판매 이력을 '상품명,브랜드,카테고리,키워드,시즌,판매수' 줄로 붙여 넣어 브랜드·카테고리·키워드·시즌 중 무엇이 판매를 설명하는지, 어느 값을 더 올릴지 정한다.
- 배송비·반품 비용을 건당 비용에 넣어 수수료 7%만 보던 영상 계산이 실제 순마진을 얼마나 과대평가하는지 확인한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '무재고 유통 키트(판매가·등록시간·팔린 이유 4축)' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from dropship import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
