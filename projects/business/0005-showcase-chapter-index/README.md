# 0005 서비스 챕터 색인

## 어느 영상에서 왔나
- 제목: AI 1인 기업가가 된 129명의 농부, 빵집 사장, 은퇴자, 주부들
- 주소: https://www.youtube.com/watch?v=aE7oIEgoNsw
- 요약: [summaries/aE7oIEgoNsw.md](../../../summaries/aE7oIEgoNsw.md)

## 무엇을 하나
영상 설명란의 챕터(시간 + 서비스 이름: 한 줄)를 읽어 바로가기 링크가 붙은 표를 만든다. 입력은 챕터 12줄 샘플(chapters_sample.txt)이다. 샘플은 중간을 건너뛰어서 "길이" 열은 실제 길이가 아니라 다음 줄까지의 간격이다.

## 실행 방법
```
python3 index.py
```

## 직접 실행한 결과 (2026-11-12)
```
| 시작 | 서비스 | 한 줄 | 길이(분) | 링크 |
| 0:03:17 | 아우라 주얼리 | 반지 가상 착용 | 2.8 | [이동](...&t=197s) |
... (12줄)
가장 오래 다룬 서비스: 탭훈민   # 샘플 간격 때문에 나온 값
성공
```

상태: **동작 확인** — 12줄이 모두 파싱되고 시작 시간(8:31=511초) 검사가 통과했다.
