# 0001 스마트폰 유즈 루틴 키트

## 어느 영상에서 왔나
- 제목: AI에게 내 스마트폰을 맡겼습니다, 컴퓨터 유즈 말고 스마트폰 유즈 (THE FOUNDER EP.2, 21분)
- 주소: https://www.youtube.com/watch?v=K4QdeGqTSfQ
- 요약: [summaries/K4QdeGqTSfQ.md](../../../summaries/K4QdeGqTSfQ.md)

## 영상이 알려 준 것(핵심)
- 컴퓨터 유즈 = AI에게 눈(화면 보기)·두뇌(판단)·손(클릭·입력)이 생기는 것. API 키·호출 제한 없이 사람처럼 움직인다.
- 화면 읽는 순서: 접근성 트리(JSON, 토큰 적음) -> 막히면 스크린샷(픽셀 전부라 토큰 많음). 웹은 HTML을 직접 읽는다.
- 아이폰 미러링으로 폰을 컴퓨터에 띄우면 Claude·Antigravity·ChatGPT가 스레드 글쓰기, 쿠팡 가격 비교·장바구니, 네이버 블로그 발행까지 한다.
- 입력이 잘 안 될 때 ChatGPT는 텍스트 파일에 글을 먼저 쓰고 복사해 붙여넣었다. 속도는 ChatGPT가 가장 빠르고 Antigravity는 잘 되지만 조금 느리다.
- 결론: 실시간으로 지켜보지 말고, 시간표(루틴)를 촘촘히 적어 맡기고 속도보다 토큰·비용으로 판단한다.

## 무엇을 만들었나
`routine.py`: 내 하루 루틴(`08:00 threads 글쓰기`)을 넣으면 (1) 시간순 시간표, (2) 앱별로 화면 읽는 방법과 토큰 어림, (3) 결제·로그인·매매 같은 '사람 확인' 단계 표시, (4) 영상 속 AI별 특징 메모, (5) 그대로 붙여 넣을 AI 지시문을 만든다.
`agent.py`: 가짜 폰으로 '접근성 트리(JSON) 읽기 -> 행동 고르기'를 연습하는 부속 예제(계정·결제 위험 없음).

## 실행 결과(실제 실행)
- 기본 루틴 4개: 시간표·지시문 생성 성공. 미러링 앱은 스크린샷 기준 약 36,000토큰(화면 12장, 가정값), 웹(크롬)은 HTML 읽기 기준으로 더 적게 나옴.
- 입력 검증: 잘못된 줄·25시 같은 시간은 건너뛰고 알려 줌, 결제·매매 단어가 있으면 '사람 확인'으로 표시. 자동 시험 통과.

## 한계(미확인)
- 실제 아이폰 미러링·AI 도구로 폰을 조작해 본 것은 아니다. 이 키트는 '무엇을 어떻게 맡길지' 설계와 지시문을 만드는 도구다.
- 토큰 수치는 가정값이다. '미러링 화면은 접근성 트리가 잘 안 잡힌다'는 부분은 추정이며 영상이 직접 말한 것이 아니다.
- '사람 확인' 안전장치는 영상에 없는 제안이다.

## 이렇게 활용할 수 있어요
- 내 반복 작업(스레드 글, 블로그 발행, 가격 비교 등)을 시간표로 적으면 AI에게 그대로 붙여 넣을 하루 지시문이 나온다. 영상의 결론대로 실시간으로 지켜보지 않고 루틴으로 맡기는 용도다.
- 앱마다 AI가 화면을 읽는 방법(접근성 트리 -> 스크린샷, 웹은 HTML)과 토큰 비용 어림을 보고, 비용이 큰 단계를 줄일 방법을 정한다.
- 결제·주문·로그인·매매·삭제 단계를 자동으로 표시해, 사람이 확인해야 하는 지점을 지시문에 '멈추고 물어봐' 문구로 넣는다(영상에는 없는 안전장치).
- 영상에서 비교한 ChatGPT·Antigravity·Claude의 특징 메모로 어떤 AI에 어떤 루틴을 맡길지 고르고, agent.py 연습용 가짜 폰으로 '화면을 JSON으로 읽고 행동 고르기'를 계정 위험 없이 연습한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '스마트폰 유즈 루틴 키트' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from routine import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
