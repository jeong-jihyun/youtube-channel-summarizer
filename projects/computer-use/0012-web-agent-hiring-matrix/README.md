# 웹 AI 에이전트 고용 비교표

## 어느 영상에서 왔나
CONNECT AI LAB '웹 잘하는 AI 에이전트, 누구를 고용할까? 뮤즈부터 컴퓨터 유즈까지 | AI 야학당' (https://www.youtube.com/watch?v=p7KaCOuJP2M, 38:54). 자막 전체(약 1만 7천 자)를 끝까지 읽었다.

## 영상이 알려 준 것(핵심)
- 웹 브라우저에서 일하는 AI 직원 6명은 겉은 비슷해도 '어디서 일하나'와 '서로 어떻게 소통하나'가 달라 비용·속도·위험이 다르다.
- 뮤즈·피클: 미국 클라우드의 컴퓨터에서 일한다. 내 컴퓨터가 필요 없고 거의 무료이며 폰에서도 명령되지만, 느리고 인스타·유튜브가 '이상한 접속'으로 막을 수 있고 앱은 못 연다.
- 크롬 익스텐션: 내 크롬 안에서 일해 빠르지만, 클로드·ChatGPT 확장끼리는 서로 소통이 안 된다.
- 어사이드: 한 집에 여러 모델을 초대하고 대화 기록을 공유하지만 신생이라 메모리를 많이 쓴다. 에고라이트: 가볍고, 기존 개발 도구에 스킬로 붙여 바탕화면 텍스트 파일로 소통시킨다. 컴퓨터 유즈: 컴퓨터 전체를 움직이지만 느리고 비싸다.
- 실습: 인스타그램 릴스에 'CODE' 댓글을 달면 답글+DM을 자동으로 보내게 하는 프롬프트(다른 게시물은 건드리지 말 것).
- 일상 루틴(10시 운동 영상, 12시 명상 등)부터 연습하고, 에이전트를 시스템화하는 것이 관건이라는 말과 전용 컴퓨터(맥 스튜디오 약 1천만 원)가 인건비를 대체한다는 주장.

## 무엇을 만들었나
`hiring_matrix.py` 의 `api()` 하나가 5가지를 한 번에 낸다: ① 내 상황 8가지 조건으로 6명의 순위와 이유(앱 제어·폰 전용은 불가로 걸러냄) ② 인스타 CODE 댓글 지시문(빠진 칸 점검, 처음 5명만 처리, 보안 경고 시 정지) ③ 여러 에이전트용 공유 텍스트 파일 규칙 ④ 하루 루틴표와 겹침 점검 ⑤ 손익분기 개월.

## 실제 실행 결과(기본 입력: 로그인 민감 Y, 여러 모델 Y, PC 보통, 예산 무료)
1. 어사이드(Aside) 95점
2. 에고라이트(Ego-lite) 85점
3. 크롬 익스텐션(클로드·ChatGPT 확장) 50점
4. 피클(Pickle) 40점
5. 뮤즈(Muse, 메타) 40점
6. 컴퓨터 유즈 40점

(1·2위 판단 이유와 ②~⑤ 전체 출력은 실험실 화면이나 `python3 hiring_matrix.py` 로 확인.) 시험 14개(표준 3종 + 추가 11개: 앱 필요 시 컴퓨터 유즈만 남음, 폰 전용 시 뮤즈·피클만 남음, 낮은 사양 감점 20점 등) 통과.

## 한계(미확인)
- 점수 숫자는 영상에 없다. '저렴하다·느리다·무겁다' 같은 말을 내가 점수로 바꾼 경험칙이다.
- 각 제품의 실제 기능·요금은 영상 시점 설명이며 직접 설치해 확인하지 않았다. 인스타 자동 댓글·DM이 정책에 맞는지, 손익분기의 월 절감액·운영비는 가정값이다.
- 영상 설명란의 프롬프트 원문(aicitybuilders 페이지)은 열어 보지 않아, 지시문은 영상에서 말한 구조를 옮긴 것이다.

## 이렇게 활용할 수 있어요
- 내 상황(앱 제어·폰 전용·로그인 민감·여러 모델·PC 사양·예산)을 넣으면 뮤즈·피클·크롬 확장·어사이드·에고라이트·컴퓨터 유즈를 이유와 함께 순위로 보고, 불가능한 후보를 미리 걸러낸다.
- 인스타그램 'CODE' 댓글 → 답글+DM 실습 지시문을 내 계정·게시물·문구로 만들어 에이전트에 붙여 넣고, 처음 5명만 처리하는 안전 규칙까지 포함한다.
- Claude·ChatGPT 같은 에이전트를 여럿 쓸 때 바탕화면 텍스트 파일 하나로 서로의 의견을 읽고 이어 쓰게 하는 규칙을 한 번에 만든다.
- 하루 루틴을 시각순 표로 만들고 같은 시각 겹침을 잡으며, 전용 컴퓨터를 사면 몇 개월 만에 회수되는지 내 숫자로 계산한다.

## 모바일(휴대폰)에서 바로 쓰기
https://jeong-jihyun.github.io/lab/ 를 열고 '웹 AI 에이전트 고용 비교표(6명 순위·인스타 CODE 댓글 지시문·공유 파일 규칙·손익분기)' 카드를 눌러 값을 바꾼 뒤 **실행**을 누른다. 서버가 필요 없고, 처음 실행은 파이썬을 내려받느라 10~20초 걸린다.

## 내 컴퓨터에서 시험·실행
```
make test      # 자동 시험 (python3 -m unittest -v test_project)
make run       # 웹 화면 실행 -> http://localhost:8000 (PORT=9000 make run 으로 포트 변경)
```
- 파이썬 코드에서 직접 부르기: `from hiring_matrix import api; api({...})`
- 다른 프로그램에서 부르기: `GET http://localhost:8000/api/run?키=값` (JSON 응답), 상태 확인은 `/health`

## 배포
```
make docker    # 컨테이너로 빌드·실행 (http://localhost:8000)
```
Dockerfile 이 있으므로 Render·Fly.io·Cloud Run 등 컨테이너를 받는 곳에 그대로 올릴 수 있다. 자세한 순서는 저장소의 docs/GUIDE.md 참고.
