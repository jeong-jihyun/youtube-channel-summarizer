# 0원으로 AI 1인 사업 시작하기 EP.1 (Start an AI Solo Business for 0 Won | EP.1)

- 영상 주소: https://www.youtube.com/watch?v=l_BNmIsuNVU
- 올린날: 2026-05-30 / 길이: 26:47 / 조회 약 5.2만
- 읽은 범위: 설명·챕터 전체 + 자막 전체(영어 제공 자막 약 2만 3천 자, 끝까지 순서대로 읽음)
- 분류: web-dev (웹·앱 개발)

## 한 줄 요약
구글 Stitch 2.0에서 Design.md(디자인 작업 매뉴얼)로 전자책 판매 사이트를 디자인하고, MCP로 Antigravity IDE에 가져와 React로 개발·시뮬레이션·자동 디버깅까지 하는 'AI 1인 사업' 첫 편.

## 영상이 파는 핵심 가치
'디자인 → 코드 → 실행'을 AI 에이전트 둘(Stitch=디자인, Antigravity=개발)과 MCP 연결로 한 번에 잇고, 고객 시점으로 계속 다듬는다. 핵심은 도구 이름이 아니라 (1) 디자인 규칙을 문서(Design.md)로 먼저 주입, (2) 연결 순서, (3) 결제 수단은 내 상황(한국 거주·해외 고객)으로 고르는 판단, (4) 오류는 통째로 붙여 넣어 자동 수정.

## 핵심 노하우
- Design.md(2:25~3:38): Stitch는 '.md를 올리면 사이트를 만든다'. 색·글꼴·버튼 모서리가 들어 있다. 바꾸려면 Gemini에 '흰 배경으로, 눈에 잘 띄게 고쳐 줘' 하고 새 본문을 붙여 넣는다. 모델은 3보다 3.1이 더 오래 생각한다.
- 페이지(4:24~6:55): 메인 페이지 먼저, 그다음 '여러 페이지 만들어'. 영상은 강의 대신 전자책을 팔기로 바꿔 상세·라이브러리·구매 완료·다운로드를 만들었다. AI가 구성을 되묻고 확인하면 진행. 페이지를 눌러 '이 부분 바꿔'라고 부분 수정.
- 결제(8:40~): 가상화폐는 뺐다. PayPal과 Stripe가 있는데 Stripe는 한국에서 공식 사용이 안 되고 미국 법인(Stripe Atlas)이 필요해 초기 비용이 있어서 PayPal로 간다. 한국 결제는 토스페이먼츠에 문의. 결제는 스스로 조사해 적용하라고 강조.
- 색 수정(9:58~): design.md에서 색을 고르고 '저장 및 적용', 원래 색 코드를 다시 입력해 되돌린다.
- MCP 연결(11:45~14:09): 화면 모두 선택 → 점 3개 → Export → MCP → API 키 → IDE 선택. Antigravity IDE(2.0이 아님)에서 MCP 서버 → Stitch 설치 → 키 붙여 넣기 → 활성화. API 키는 '내가 진짜 주인임을 증명하는 열쇠'.
- 가져오기(15:34~): 새 폴더에서 Export → MCP → 프롬프트 복사/붙여 넣기. 프로젝트 목록 → 화면 목록 → 각 화면의 ID로 가져온다. 'Stitch Screens' 폴더에 design.md·화면 이미지·코드가 생긴다. 한국어 설명은 '한국어로 설명해 줘'.
- 개발(19:00~): 'React로 개발, localhost에서 보게 해 줘' → 계획 확인 → npm run build 확인 후 실행. Claude Code는 터미널에서 켤 수 있지만 유료라 모든 것을 맡기지 않는다(로컬 AI·Gemini 병행 언급).
- 시뮬레이션·디버깅(22:00~): 전자책 선택→상세→결제까지 따라가는 시뮬레이션 지시. 오류가 나면 전부 복사해 붙여 넣으면 스스로 원인을 찾아 고친다(예전엔 공백·마침표 하나로 사이트가 멈췄다). 아이콘이 글자로 보이면 '전체를 보고 개선'. 항상 고객 시점으로 불편을 찾는다.
- 다음 편(26:08): 데이터베이스(누가 무엇을 샀는지)와 PayPal 결제 연결.

## 영상 속 실습 결과
화면으로 Stitch 생성, MCP 연결 성공, 로컬 React 사이트 실행, 시뮬레이션 중 오류를 붙여 넣어 고친 장면을 보여 준다. 수치로 된 성과는 없고 재현은 하지 않았다.
