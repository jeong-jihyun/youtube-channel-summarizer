## 한 줄 요약
AI가 사람처럼 화면을 보고 마우스로 누르는 "컴퓨터 유즈"를, 아이폰 미러링으로 스마트폰까지 넓혀 쓰는 방법을 보여 준다.

## 핵심 5줄
1. 컴퓨터 유즈는 AI가 화면을 보고(눈) 판단하고(두뇌) 클릭·입력(손)하는 방식이다.
2. 예전 자동화는 플랫폼의 API 허락과 키가 필요했지만, 컴퓨터 유즈는 사람과 똑같이 움직여 그 제약이 줄어든다.
3. 화면을 읽는 순서: 접근성 트리(JSON, 토큰 절약) 먼저, 막히면 스크린샷, 웹은 HTML 직접 읽기.
4. 아이폰 미러링으로 폰을 컴퓨터에 띄우면 Claude·Antigravity·ChatGPT가 폰을 조작해 스레드 글, 쿠팡 장바구니, 네이버 블로그를 처리한다.
5. 실시간으로 지켜보기보다 "루틴으로 적어 맡기기"가 속도·비용 면에서 낫다.
