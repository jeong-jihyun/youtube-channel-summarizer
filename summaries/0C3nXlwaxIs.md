# AI에게 네이버 블로그 맡겼습니다 | 설치부터 자동 발행까지 왕초보 무료 강의

- 올린날: 2026-09-20 / 길이: 24:17 / 조회 112,989
- 읽은 범위: 설명·타임라인 전체 + 자막 전체(끝까지 순서대로 읽음)
- 분류: automation (업무·콘텐츠 자동화)

## 한 줄 요약
AI 브라우저 'Aside'를 설치해 모델을 연결하고, 육하원칙 지시문을 '루틴'으로 등록해 매일 오전 8시 AI 뉴스를 검색·작성해 네이버 블로그에 자동 발행하는 과정을 보여 주는 무료 입문 강의.

## 영상이 파는 핵심 가치
'비싼 자동화 강의 없이도 AI 브라우저 + 잘 쓴 지시문 + 루틴으로 블로그를 자동 운영한다'. 핵심은 도구 설치가 아니라 일 잘 시키는 지시문(육하원칙+단계+마무리)과 안전한 시작(초안 저장 먼저)이다.

## 핵심 노하우
- AI 브라우저 개념(1:28~5:32): 브라우저에 AI를 연결하면 사람을 한 명 고용한 것과 같다. 이전 시도는 봇 확인에 막혔고, Aside는 오픈소스 Chromium 기반으로 그 장벽을 제거했다고 설명. Aside는 AI를 새로 만들지 않고 기존 AI에 '도구(손발, 하네스)'를 붙인다.
- 모델 연결 3방식(6:18~9:28): ① 무료 크레딧(약 500) ② 구독 연결(ChatGPT·Claude·Grok 구독을 로그인으로 연결, Gemini 구독은 연결되지 않는다고 말함) ③ API 키(구글 AI Studio 키처럼 쓴 만큼 지불, 가끔 쓰면 구독이 아까울 때) ④ 로컬 AI(LM Studio·Ollama 키 연결, 일반 컴퓨터에는 AI 브라우저 요구량이 커서 한계).
- 사고 수준 선택: 기본/낮음/중간/높음/매우 높음/최대. 높을수록 토큰을 많이 쓰므로 블로그 글은 '중간'이면 충분.
- 프로젝트 만들기: '블로그 자동화 수업' 폴더를 만들어 거기서 관리. 탭 이해(10:49~), 채팅 vs 루틴(11:40~).
- 지시문 작성(15:11~17:37) — 육하원칙: ① 언제: 매일 오전 8시 한국 시간 ② 어디서: X, 네이버, 구글, 네이버 블로그 ③ 방법: 1) X에서 키워드로 AI 동향 2) 네이버에서 AI 뉴스 3) 구글에서 AI 뉴스 4) 1·2·3의 공통 키워드를 찾아 사실 여부를 판단하고 대중에게 도움이 되게 쉽게 쓴다 ⑤ 마지막에 채널 홍보 문구와 주소. 목표와 상세 절차를 '매뉴얼'처럼 준다.
- 발행 방식 선택(17:37): 초안 저장(사람이 확인 후 발행) vs 자동 발행. 처음에는 초안으로 시험하라는 것이 설명란의 안내.
- 즉시 시험(18:25~): '지금 테스트로 한 건 올려' → AI가 4단계로 쪼개 후보 확인 → 공식·신뢰 출처로 사실 확인 → 발행까지 진행. 시험 중 루틴이 겹쳐 2개가 중복 등록되어 하나를 지우고 목록을 다시 확인(20:05).
- 비용(21:13): 무료 크레딧 → 월 20달러/200달러 요금제, 또는 기존 구독 연결, 또는 API 종량제, 또는 로컬. 광고 없음을 강조.
- 설명란 주의: 도구 요금·무료 제공량·지원 범위 변동, 자동 실행에는 실행 환경·로그인·권한 필요, 사실관계·저작권·사이트 이용정책 확인 후 발행, 수익·노출 보장 없음.

## 영상 속 실습 결과
Aside 설치, 이름 'Brown' 지정 후 네이버 블로그 편집기 인식, 루틴 등록(첫 실행 9월 20일), 테스트 발행 1건(AI 허위 보도 관련 글), 중복 루틴 삭제. 재현은 하지 않았다.
